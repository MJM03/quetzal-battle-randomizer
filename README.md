# Quetzal Battle Randomizer

Generador PWA de equipos Pokémon para partidas casuales de Pokémon Quetzal.

## Funciones
- 2 a 4 jugadores
- 3 o 6 Pokémon por jugador
- Nivel 50 o 100
- Modo Balanceado o Random total
- Permitir/bloquear legendarios y míticos
- Evitar especies repetidas entre jugadores
- IV 31 como regla visual
- Repetir un Pokémon o un equipo completo
- Instalable como PWA

## Ejecutar
Sirve esta carpeta con cualquier servidor estático (GitHub Pages, Netlify, Vercel, etc.).
